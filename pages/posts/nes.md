I began programming on the web as a teenager: Perl, PHP, CGI scripts were how I learned.
Later on came Python & Django, and these days I mostly build systems in Go. The type of
systems I've spent my career building began as community-oriented websites (with forums
and inventory management systems) until eventually landing in enterprise software, where
complexity is high and reliability and security aren't nice-to-haves.

Throughout that career, I never had the chance to build systems-level software, like what
I've experienced as I've built my [NES emulator](https://github.com/bartek/zignes). I've
been writing it in Zig, which is a language I can slowly learn without the worries of
haste and efficiency which come with building commercial software.

It's been a slow process, primarily because it is a side project. I first tried out a Game
Boy emulator which I coined [zigboy](https://github.com/bartek/zigboy). I got to around
the PPU before giving up, my brain just couldn't wrap around it. That was in 2024. A year
or so later in the winter of 2025 I began [zignes](https://github.com/bartek/zignes/) and
I've been tackling that since. As of this writing, the NES emulator renders graphics,
produces sound, and a few of the games I've sampled are playable.

There is still much work to be done. The screen flickers and glitches out oddly, and some
games don't work at all yet! This page represents a few resources I've gathered along the
way.
